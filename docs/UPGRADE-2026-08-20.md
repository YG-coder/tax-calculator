## 2. ESLint flat config 도입

Next 16에서 `next lint` 명령이 제거되어 `eslint.config.mjs`를 신규 작성했습니다. 진행 중 확인한 두 가지 함정:

**(1) ESLint 10은 아직 쓸 수 없음.** 최신은 10.8.1이지만 `eslint-config-next@16.3.1`이 의존하는 `eslint-plugin-react`가 ESLint 10의 변경된 context API를 지원하지 않아 룰 로딩 단계에서 실패합니다.

```
TypeError: Error while loading rule 'react/display-name':
contextOrFilename.getFilename is not a function
```

→ eslint는 `^9.39.5`(9.x 최신)로 고정. 추후 eslint-plugin-react가 ESLint 10을 지원하면 재검토.

**(2) `FlatCompat` 방식은 쓰면 안 됨.** 인터넷에 흔한 `@eslint/eslintrc`의 `FlatCompat`으로 `next/core-web-vitals`를 extends 하면 순환 참조 오류가 납니다.

```
TypeError: Converting circular structure to JSON
```

Next 16의 `eslint-config-next`는 flat config를 서브패스로 직접 export(`./core-web-vitals`, `./typescript`)하므로 그대로 import 하면 됩니다. `@eslint/eslintrc` 의존성도 불필요.

```js
import nextCoreWebVitals from "eslint-config-next/core-web-vitals";
import nextTypeScript from "eslint-config-next/typescript";

const eslintConfig = [
  { ignores: ["node_modules/**", ".next/**", "out/**", "build/**", "next-env.d.ts"] },
  ...nextCoreWebVitals,
  ...nextTypeScript,
];

export default eslintConfig;
```

## 3. lint 도입으로 드러난 기존 코드 정리

업그레이드와 무관하게 원래 있던 문제들. lint를 처음 켜면서 검출됨.

| 파일 | 내용 |
|---|---|
| `FreelancerTaxClient.tsx` | `react/no-unescaped-entities` 6건 — JSX 텍스트의 `"` → 곡선따옴표 `“ ”` |
| `VatCalculatorClient.tsx` | 같은 룰 10건 — 동일 처리 |
| `WithholdingClient.tsx` | 미사용 변수 제거: `handleCalc`(빈 useCallback), `netPay`, `totalTax`, `localTax` + 미사용 `useCallback` import |

`WithholdingClient`의 `localTax`/`totalTax`는 자녀세액공제 반영 전 중간값으로, 화면 표시에는 `finalLocalTax`/`finalTotal`만 사용되고 있었습니다. 즉 죽은 코드였고 **표시 결과는 변하지 않습니다.** 지방소득세 10% 근거 주석은 `finalLocalTax` 쪽을 가리키도록 옮겨 유지했습니다.
