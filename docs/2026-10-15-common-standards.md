# 세금계산기 공통 기준 적용 — 2026-10-15

로컬 수정·검증 기록이다. 푸시·운영 배포·수정 후 운영 확인은 미실시이며 §13-4의 운영 완료로 표시하지 않는다. 확인 주체는 Codex(AI)이며 사람 검수나 실기기 검수가 아니다.

## 주소 기준

- 처리·검색용 정본: `https://taxsim.kr` (`src/lib/site.config.json`, `src/lib/site.ts`).
- 표시용 주소: `https://taxsim.kr`. 두 주소의 정규화된 origin이 같아야 한다.
- metadataBase와 Next.js 기본 URL 처리를 유지한다. canonical·OG·사이트맵·robots·자사 JSON-LD는 정본에서 생성한다.
- 복합 헤더 전체를 URL로 해석하지 않는다. robots Host는 호스트명/URL을 구분한다. JSON-LD의 @context는 제외하며 합법적인 외부 출처·이미지가 필요한 경우 명시적 허용 목록으로 관리한다.

## 검증 증거와 범위

- 정적 분석, 타입 검사, 전체 회귀 검사, 프로덕션 빌드 통과.
- `npm run build`가 `scripts/check-site-urls.mjs`를 실행한다. 사이트맵 39페이지와 사이트맵 밖 색인 허용 페이지까지 총 39페이지의 canonical·og:url 경로, 자사 origin, OG/Twitter 절대 이미지 주소, 큰 카드, JSON-LD, robots, 실제 이미지 파일 존재를 검사한다.
- 생성 HTML과 대표 상태의 렌더 텍스트에서 camelCase/snake_case 식별자를 검사한다. 소스 AST에서 동적 조사 하드코딩을 검사한다. 프레임워크 내부 오류 문서와 noindex 경로는 색인 대상 검사에서 제외한다.
- 로컬 서버의 사이트맵 대상 39페이지·robots·사이트맵 응답을 확인했다. 대표 공유 이미지는 HTTP 200, image/png, 1200×630이었다.
- 입력·화면 회귀 범위: 실제 양도세·연말정산 빈칸/0→결과→삭제 전이, 전체 계산기 초기 문구, 연말정산 토글, 기존 세금 예제와 주소 검사.
- 기존 공식 자료/수기 기대값 검사는 재실행했지만, 이번 작업에서 법령·금융 정책을 새로 확정하거나 모든 상품 조건을 검수하지는 않았다. 테스트 수·커버리지 비율을 정확성 근거로 사용하지 않는다.

## 유지한 조건

종부세의 선택 입력은 원래 null을 사용하며 추정·상한 미적용 이유를 안내한다. 이를 임의의 0으로 바꾸지 않는다. 일반적인 선택 공제 입력은 미선택 상태를 유지하며 결과에서 제외됨을 안내한다. 외부 기관 출처·schema.org 문맥은 자사 도메인으로 고치지 않았다.
